# Flowtu Studio — 四轨 DAW 原型

Vue 3 + Vite + 原生 Web Audio。四条轨道支持音频和音符片段混排，参考视频只用于同步预览。演示音频在本地程序化生成，没有第三方音乐素材。

## 运行

要求 Node.js 22+ 和 pnpm。

```sh
pnpm install
pnpm dev
```

```sh
pnpm test
pnpm build
pnpm preview
```

`dist/` 是可部署到静态托管服务的完整产物，无服务端依赖、无账号登录依赖、无外部运行时 CDN。首次播放需用户点击播放按钮。

## 已实现

- 固定四条轨道，各自支持音量、静音和独奏。
- 本地音频导入、拖入轨道、波形显示、移动、边缘裁剪、数字入点/长度、替换、分割、复制和删除。
- 音符片段：C3–B4 基础钢琴卷帘、添加/移动/拉伸/删除音符、力度、1/16 网格、柔和三角波琴音。是基础合成音色，不是真实钢琴采样库。
- 工程播放、暂停、停止、定位、循环、BPM、主音量和撤销/重做。
- 单个参考视频：导入、静音预览、全屏、替换/移除；与工程同步定位、播放和暂停。音频时钟为主，视频偏差超过 120 ms 时纠正；属于浏览器预览同步，不承诺逐帧锁定。视频结束后音频可继续播放。
- WAV 离线混音导出：16-bit PCM、44.1 kHz、立体声，采用与实时播放同一调度逻辑，遵循静音/独奏/音量设置。不包含视频原声。
- 手动保存到 IndexedDB，包含音频素材、视频、音符和工程参数；刷新恢复最近保存的版本。
- `.flowtu` JSON 工程导入/导出，包含音频和音符；为避免大型文件，导出的工程不包含参考视频，重新打开时需重新选择视频。

## 原型边界

- 最长 180 秒。单个音频文件最多 50 MB，视频最多 250 MB，解码音频总缓存上限 256 MB。部分浏览器/设备的实际内存上限可能更低。
- 视频建议 H.264 MP4 或 WebM；其他音视频编码取决于浏览器解码支持。
- 没有视频剪辑、MP4 合成导出、录音、VST、音频变速不变调、效果器链或云端协作。
- 音符编辑范围 C3–B4；基本节拍与音频剪辑，BPM 变化只调整音符片段长度/音符时值，不对音频素材自动变速。
- 保存是手动的，清理站点数据会删除浏览器本地工程。应通过导出工程文件另存备份。
- 编辑/拖动时暂停，避免修改过程中出现旧调度声音。浏览器视频缓冲时暂停工程，画面就绪后可继续。
- 桌面优先；窄屏可基本操作。触摸端的手势、各种设备低延迟表现、长时间多素材使用尚需进一步验证。

## 接入 Flowtu / Nuxt

当前为独立可运行原型，尚未接入 Flowtu 账号、素材库或云端工程 API。

1. 将 `src/` 作为独立音频工作室模块迁入 Vue 项目；Nuxt 中使用 `.client.vue` 或 `<ClientOnly>`，确保 AudioContext 和 IndexedDB 仅在客户端创建。
2. `App.vue` 管理交互状态；`engine.js` 负责音频；`core.js` 提供调度区间、分割和 WAV 编码；`storage.js` 是本地存储适配层。
3. 接入平台时用 Flowtu 的素材下载接口提供 ArrayBuffer，通过 `engine.addAsset` 加载。视频交给 `<video>`，素材跨域服务器需提供合适的 CORS 策略。
4. 将 `projectData` / `restore` 与平台工程读写接口对接，正式数据模型建议将音视频素材独立存储，工程只引用素材 ID，不在 JSON 中嵌入大型音频。
5. 迁入既有页面前应为 `style.css` 增加模块命名空间，避免全局 button/input 样式影响其他业务页面。
6. 可先把独立构建部署到 Flowtu 的一个子路径/子域，以独立页面验证，再做深度 UI 集成。生产环境应使用 HTTPS。

## 验证记录

- 六项 Node 测试通过：裁剪后定位、分割音频连续性、跨分割点音符保留、静音/独奏、WAV 格式和工程校验。
- 浏览器实际验证：示例播放、数值裁剪、真实 WAV 导入、音符添加/拖动/撤销、MP4 导入、视频静音同步播放、跳到 4 秒定位、保存后刷新恢复素材。
- 已实际导出并用 FFmpeg 检查 16 秒、44.1 kHz 双声道 WAV，输出非静音。
- 测试素材位于忽略的 `test-results/`，不包含在发布源代码与站点中。
