Flowtu Studio - openDAW

Built on openDAW 0.3.2, with a four-track starter, editing toolbar, track automation, reference-video synchronization and portable project files.

License: AGPL-3.0-or-later. Original copyright and attribution notices are retained in the source.

  • Download this modified source, lockfile and build instructions
  • Matching upstream source, SDK and WASM engine
  • Full AGPL license

With Node.js 23+ and pnpm 11, run pnpm setup then pnpm build from the source root. SDK and engine versions are pinned by the lockfile; matching TypeScript and Rust sources are linked above.

Audio and video files are processed in your browser. Reference video is not edited or mixed into the WAV export.
